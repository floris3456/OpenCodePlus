`tools.instructions.*` edits agents/tools/base/skills/system/MCP/models/teams/perms. Ids: `item:<level>:<agent|''>:<itemId>`, `section:…:<sectionId>`, `agent:<level>:<id>`, `team:<level>:<name>[:<member>]`. `create` returns `{id,item}`; `show`/`set`/`delete` take that `id`. `list({where:"review:true"})`→`show({id,view:"diff"})`→`set({id,resolve:"keep"})`. `list({where:"agent:X item:tool"})`→`set({id,text})`. Patterns are core wildcards, not regex; shell resource is the parsed command, so `git *` matches bare `git`. Skill `instructions-tools`: filters, views, presets, create/delete, errors.
