## Gate recipe (written before anything was run)

Everything lives under this run's tmp directory; nothing reads or writes the
human's live `~/.config/opencode`, and the stale `gate/` directory of the
previous orchestrator is never touched.

```
GATE = <run tmp>/opencode/gate-r2r8

                                    sanctioned workspace generator
                                    `bun scripts/team/oc2-config.ts` with
                                    XDG_CONFIG_HOME=$GATE/config, then the
                                    v1 `mcp.servers.search` block stripped.
                                    Mode 0600; never printed, never committed.
  config/opencode/opencodeplus/instructions/records.jsonl
                                    {"version":2,"revision":1} header plus
                                    a defaults-level team record enabling
```

Launch (mechanical, reused verbatim for the R7 restart):

```sh
cd $GATE && nohup sh start-server.sh > server.log 2>&1 &
```

`start-server.sh` sources `env.sh` and runs, from the task worktree:

```sh
bun --preload $REPO/packages/plus/bin/restore-cwd.ts --cwd $REPO/packages/cli \
    $REPO/packages/cli/src/index.ts serve --hostname 127.0.0.1 --port 40931
```

with `XDG_CONFIG_HOME/DATA_HOME/STATE_HOME/CACHE_HOME` and `TMPDIR` under
`$GATE`, `OPENCODE_TUI_CHANNEL=plusgate`, `OPENCODEPLUS_CALLER_CWD=$PROJ`,
`OPENCODE_PASSWORD` read from `$GATE/password`, and
`OPENCODE_CONFIG_PROJECT_DISABLE` unset. Port **40931** (40931/40932/40933 were
all free at setup time; 40931 chosen).

Team state root for this gate (audit.log, runs/, receipts):
`$GATE/home/data/opencode/opencodeplus/teams/` (that is
`teamsDataDir()` = `$XDG_DATA_HOME/opencode/opencodeplus/teams`).

real prompts to real models. No fakes, no scripted child, in any round.
